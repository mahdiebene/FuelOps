SMALL SYSTEM. EXPLICIT BOUNDARIES.

From observation to accountable action.

The public viewer explains the system. The private operator application owns simulator access, approval, and durable execution.

01

Observe

Validate official inventory, routes, demand profiles, and incoming fuel. Retain a last-good view when data degrades.

02

Anticipate

Project 48 ticks of demand. Account for inbound shipments, physical capacity, depot stock, and route constraints.

03

Approve

A human reviews each feasible proposal. Execution is paused/manual only; stale data and uncertain writes block new dispatch.

04

Reconcile

Persist intents in SQLite, suppress exact-key duplicates, and reconcile uncertain outcomes before another shipment.

What this public site can—and cannot—do

  • Explore a sanitized, dated snapshot from the official participant simulator.
  • Inspect historical measured outcomes without concealing ties or trade-offs.
  • Download only the same sanitized data already displayed here.
  • No operator API, simulator proxy, authentication token, writable database, dispatch, reset, or admin endpoint is deployed here.
  • Data does not refresh from the private simulator. Updating it requires a reviewed export and redeployment.
